# Security reporting

Simulator-only portfolio software, maintained by Jason Stys. Do not connect real
aircraft, upload sensitive records or expose the temporary test server. Read
[threat model and limitations](docs/SECURITY.md) before running.

Report non-sensitive defects through repository issues. Contact
[Jason Stys](https://www.linkedin.com/in/jason-stys-31b30b351/) to arrange private
disclosure before sending a vulnerability or sensitive evidence. Never include
passwords, session cookies, production connection strings or personal flight data.
There is no claimed security certification, guaranteed response time or bug bounty.
